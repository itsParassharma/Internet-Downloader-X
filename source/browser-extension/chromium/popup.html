Connection setup

Install and open the IDX Windows app once. It connects to this extension automatically. If needed, open IDX > Options > General > Extension setup and choose Reconnect browser.

Paste a direct file link, or right-click a link and choose “Download with IDX”.

Automatic downloads

On by default. IDX pauses the browser copy during handoff and resumes it if the desktop app cannot accept it.

The panel appears over detected web players. Click the arrow to choose a file or stream quality. Completed HLS and static DASH streams are supported, including separate audio tracks. Browser login cookies are passed securely to IDX when needed. The toolbar icon enables or disables IDX on the current tab.

One site per line. Subdomains are included. Private downloads stay in the browser.
