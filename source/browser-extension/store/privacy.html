IDX Extension Privacy

Updated 18 October 2026 - Extension version 0.7.0

IDX connects Chrome to the IDX download manager on your Windows computer.

Information used

Automatic download capture is on by default. It reads new download URLs, filenames, source pages and download state. It pauses the browser copy while the local app accepts the request, cancels that copy after acknowledgement, and resumes it if handoff fails. You can turn capture off or exclude sites.

To show the floating video/audio panel, content scripts inspect media elements and their source addresses in pages and embedded frames. The extension observes HTTP/HTTPS response metadata such as URL, media type and size. It does not read response bodies. Detected media URLs are held in session storage, expire from the displayed catalog after ten minutes, and are removed when the tab navigates or closes. Opening a stream menu sends its manifest URL and the required browser session to the local Rust helper to inspect available qualities. Choosing a download sends the selected media address to IDX.

Manual or automatic handoffs send the selected URL, suggested filename and available source-page/Referer URL to the local desktop app. The Referer may be included in the resulting request to the selected download server. For a selected download or stream inspection, the extension reads matching cookies, including HttpOnly cookies and available partitioned cookies, from the current browser session. It passes their domain, path, expiry and secure scope plus the browser user-agent to IDX. Cookies are used only on matching HTTP requests; they are never added to unrelated redirect targets. The extension does not read saved passwords or Chrome's browsing-history database. Incognito use is disabled.

Storage and sharing

Preferences, site exclusions and the latest result are stored locally. Accepted downloads and source-page addresses persist in the desktop library. Cookie values are not written to the library, extension storage or logs. The brief desktop inbox handoff uses Windows current-user encryption; its envelope is removed after acceptance. Credentials then remain in memory for that IDX session. After restarting IDX, send an authenticated link again from its signed-in browser page. Manifest inspection and segment downloads contact the selected media servers. IDX has no analytics, advertising, accounts, telemetry or publisher backend. It does not sell data or transmit it to an IDX-operated service. Download servers receive the requests and network information needed to deliver the files you request.

Your choices

Click the toolbar icon to enable or disable IDX on the current tab. Open the extension's Options page to change automatic capture, media panels, full/mini mode and site exclusions. You can restrict site access or uninstall the extension in Chrome. Removing the extension does not remove downloaded files or the desktop library.

Limited use

Information received through Chrome APIs is used only for these download features, consistent with the Chrome Web Store User Data Policy and its Limited Use requirements.
